# Attendo Web

Know exactly how many classes you can miss. A free attendance and student-life app for NIT
Trichy MCA students, built as an installable web app.

Status: planning done, build not started. The full specification is in
[docs/ATTENDO_WEB_SPEC.md](docs/ATTENDO_WEB_SPEC.md); the build runs in stages (section 18).

- `docs/` holds the spec and the account setup checklist.
- `seed/` holds the NIT Trichy data: courses, curriculum, calendars and grading.

Setup instructions (install, run, test) are added in Stage 0.
